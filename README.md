## Manual beta installation

1. Download `feedfence-2.3.3.zip` from the latest GitHub Release.
2. Extract the ZIP to a folder you want to keep.
3. Open `chrome://extensions` in Chrome or `brave://extensions` in Brave.
4. Enable **Developer mode**.
5. Select **Load unpacked** and choose the extracted FeedFence folder.

Manually installed beta versions do not update automatically. Download and
load a newer GitHub Release when one becomes available. The Chrome Web Store
release is being prepared.
