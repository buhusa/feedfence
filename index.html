Three quick steps

Install FeedFence manually.

You only need Chrome’s built-in extensions page. No installer and no FeedFence account are required.

  1. 1
    ↓

    Download and unzip

    Download the ZIP above and extract it to a folder you want to keep.

  2. 2
    ⚙

    Open extensions

    Enter chrome://extensions and enable Developer mode.

  3. 3
    ＋

    Load the folder

    Select Load unpacked and choose the extracted FeedFence folder.

Using Brave? Open brave://extensions and follow the same steps.
